# Ayushman Kaushal — Portfolio

A static developer portfolio built with HTML, CSS and vanilla JavaScript.

## Content
- Profile: Python, backend development and AI applications
- Vraify AI freelance contract under Experience
- Selected case studies: REVIVE, Packet Analyzer and Multi-API React App
- Other projects, technical skills, training, education and curated credentials
- Direct email contact (no form or backend)

Resume and freelance-services sections are intentionally absent.

## Run
```sh
python3 -m http.server 8000
```
Open http://localhost:8000. No build dependencies are required.

## Content maintenance
Edit `index.html`, `style.css` and `portfolio.js`.
Project screenshots are stored in `assets/` and can be opened at full size.
The Packet Analyzer screenshot reflects its hosted offline state as captured on November 11, 2026.
REVIVE's visual reports documented synthetic evaluation results, not production revenue or a dashboard screenshot.
Certification links point to individual credential records where available; course landing pages are not used as proof.
The legacy `latest_resume.pdf` remains in the repository but is not linked from the website.

## Accessibility
Static content remains visible with JavaScript disabled. Navigation supports keyboard use and Escape to close; a skip link and reduced-motion styles are included.
